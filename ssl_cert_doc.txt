reverse proxy setup for Jenkins ?
pre-req:
     •  Jenkins running on port 8080 (default)
     •	Domain name (https://urjenkins.duckdns.org/)pointing to your EC2 public IP
     •	Port 80 (HTTP) and 443 (HTTPS) allowed in the Security Group
     •	NGINX and Certbot packages available

1 install nginx (sudo apt install nginx -y) and check the nginx status: sudo systemctl status nginx

2 Configure Reverse Proxy: Create a new NGINX config for Jenkins:(sudo nano /etc/nginx/sites-available/Jenkins) past the code and edit the server_name: as domain for jenkins

3 Enable the configuration:(sudo ln -s /etc/nginx/sites-available/jenkins /etc/nginx/sites-enabled/)

4 After Editing: Run these commands: Test & reload NGINX:(sudo nginx -t , sudo systemctl reload nginx )

5 Install Certbot and SSL (Let's Encrypt):(sudo apt install certbot python3-certbot-nginx -y)

6 Run Certbot to get SSL:(sudo certbot --nginx -d urjenkins.duckdns.org)
